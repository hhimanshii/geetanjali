# Geetanjali Salon — React revamp

A responsive, editorial homepage for Geetanjali Salon, built with React, Vite, and Tailwind CSS.

## Run locally

```sh
npm install
npm run dev
```

Build the static site with `npm run build`. The output is in `dist/`.

## Structure

- `src/App.jsx` — page sections and layout
- `src/components/` — shared navigation, cards, heading, and footer
- `src/data/site.js` — content, source links, and image paths
- `src/styles.css` — Tailwind entry and small design helpers
- `public/images/` — existing Geetanjali photography from the original website

The booking, service, gallery, and location calls to action link to Geetanjali's current website.
